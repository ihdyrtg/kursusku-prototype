# Refleksi Pertemuan 5-6

## Pertemuan 5
`name` menentukan key data yang dikirim ke PHP, sedangkan `id` terutama menghubungkan label dan elemen. GET cocok untuk pencarian/filter yang parameternya layak terlihat dan dibookmark; POST dipakai untuk alur pendaftaran karena data dikirim pada request body. POST tidak otomatis aman tanpa HTTPS. Layout mobile dibuat satu kolom, field dibuat `width: 100%`, dan focus state tetap terlihat.

## Pertemuan 6
Branching memilih satu jalur berdasarkan kondisi, sedangkan looping mengulang proses pada data/iterasi. `if/elseif` dipakai untuk diskon peserta dan `switch` untuk label metode belajar. `foreach` dipakai pada array kursus, minat, fasilitas, dan history dummy; `for`, `while`, dan `do-while` tersedia di `loop-lab.php`. Database belum dipakai agar fokus tetap pada fundamental PHP sebelum migrasi Laravel.
